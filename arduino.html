Intro to Arduino: Physical Computing

One blinking LED → a night light that senses darkness and lets me choose its colour. 4 circuits, 7 colours.

Summary. An introduction to physical computing with Arduino. I built four circuits, each one doing something different while reusing the same ideas: setting pins, reading a sensor, and controlling an output. The four circuits are 1A Blink, 1B Potentiometer, 1C Photoresistor, and 1D RGB Night Light. The full post, with Tinkercad schematics for each circuit, is on WordPress.

Reflection

“To me my experience with the Arduino was great. The whole unit in the beginning was a little more difficult trying to learn about what all the pins do and how to connect components without breaking anything and especially figuring out how the code works. But as we moved through the unit each circuit got easier as we went on each circuit made us do something different but having to do something similar as well which helped me understand what these chunks of code meant, also where components have to go to let the code control them and deliver power without causing a short circuit, also trying to troubleshoot issues like code format or component in the wrong pin and much more.”

Why this demonstrates achievement. Each circuit builds on the last: Blink teaches output and timing, the potentiometer adds analog input, the photoresistor adds a threshold decision, and the night light combines two inputs and three outputs. I learned to wire components so the code can control them and deliver power without causing a short circuit, and to troubleshoot when the code format was wrong or a component was in the wrong pin. That progression — from a single blinking LED to a light that senses darkness and lets me choose its colour — is the achievement.
